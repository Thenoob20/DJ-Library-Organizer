# DJ Library Organizer
Please Back up your music Library 

A Python tool for DJs who need to migrate and clean large music libraries outside of Apple

Music/iTunes.
Features:
- Audit source libraries with CSV reports
- Detect genre, versions, bitrate, duplicates, and missing tags
- Organize files into a hybrid DJ folder structure
- Support copy, move, dry-run, resume, and clean-audit modes
- Generate M3U playlists for Serato and VirtualDJ
- Create One Tagger-friendly suggestion CSVs

Safe workflow:
1. Run audit
2. Run dry-run
3. Copy a small test batch
4. Test in Serato/VDJ
5. Move one genre at a time
6. Run clean audit and refine rules
Built for open-format DJs managing large, messy libraries. Test small. Back up everything. Trust the CSV.
